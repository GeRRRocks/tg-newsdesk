# Список изменений

Версии нумеруются как `основная.дополнительная.исправление`: новая возможность
увеличивает вторую цифру, исправление ошибки — третью. Каждой версии
соответствует метка в git.

## 1.2.0 — 2026-10-01

- Ответы на вопросы участников группы: сообщение с упоминанием бота, которое
  начинается со слова «Вопрос:» или «Question:», уходит в нейросеть, бот
  отвечает реплаем. Выключено по умолчанию (`QA_ENABLED`), работает только в
  целевой группе; `QA_TOPIC_ID` ограничивает ответы одним топиком.
- Лимиты на вопросы за 24 часа с первого вопроса: на участника
  (`QA_USER_DAILY_LIMIT`, по умолчанию 3) и на всех вместе
  (`QA_GLOBAL_DAILY_LIMIT`, 50). Администраторы под лимиты не попадают.
- Генерация промпта по описанию: в меню «🏷 Промт» можно описать словами,
  какими должны быть посты, и нейросеть составит промпт сама. Вариант
  применяется только после «Сохранить».
- В меню «🏷 Промт» появился второй раздел — инструкция для ответов на
  вопросы; она правится отдельно от промпта для постов. Защитные правила
  дописываются к ней автоматически и из меню не меняются.

Схема базы: новая таблица `qa_usage` и колонка `bot_settings.qa_prompt` —
создаются сами при запуске.

## 1.1.0 — 2026-10-01

- Язык бота: `BOT_LANGUAGE=ru` или `en` в `.env`. Переводятся меню и кнопки,
  сообщения администраторам, уведомления о сбоях (включая контейнер
  резервных копий) и промпт по умолчанию. По умолчанию — русский, для
  существующих установок ничего не меняется.
- `BOT_TOPIC` можно не задавать: берётся тема по умолчанию на языке бота.
- `scripts/install.sh` первым шагом спрашивает язык, ведёт диалог на нём и
  записывает его в `.env`; файл `.env` создаётся с правами 600.
  `scripts/setup-swap.sh` тоже пишет на выбранном языке.
- README на английском (`README.en.md`) с переключателем языка, раздел с
  требованиями к серверу.
- Из `.gitignore` и `.dockerignore` убраны записи, нужные только для
  локальной разработки.

Схема базы не менялась.

## 1.0.1 — 2026-10-01

- Репозиторий переименован в `tg-newsdesk`; обновлены адреса в README и
  строка User-Agent, с которой бот ходит на сайты-источники. Старые ссылки на
  GitHub продолжают работать. Имена базы, контейнеров, systemd-сервиса и
  файлов резервных копий не менялись.

## 1.0.0 — 2026-10-01

Первая версия с номером.

- Сбор новостей из RSS-фидов, обычных HTML-страниц и публичных
  Telegram-каналов; тип источника определяется автоматически по адресу.
- Рерайт новости нейросетью на выбор: Claude, GPT, Gemini или DeepSeek;
  переключение из меню бота.
- Модерация черновика: опубликовать, отклонить, запросить другой вариант,
  заменить текст своим; черновики без ответа закрываются автоматически.
- Расписание по интервалу или по дням недели, системный промпт и фильтр по
  словам — из меню, без перезапуска.
- Статистика черновиков по источникам.
- Уведомления администраторам о сбоях источников, нейросети и о неожиданных
  ошибках.
- Ежедневные резервные копии базы с выгрузкой в S3-совместимое хранилище и
  восстановление одной командой.
- Запуск в Docker Compose: изолированная сеть базы, контейнеры без лишних
  прав, файл подкачки на серверах с небольшим объёмом памяти.

Схема базы: черновики со статусом «истёк» и источники типа «Telegram-канал»
не понимает код старше этой версии.
